Land Cover Legend Creation Workflows

I. New Legend

  1. From the menu toolbar select 'File' then 'New' [Select 'New' from the shortcut toolbar].
  2. Select 'Yes' to confirm legend clearing.
  3. Select 'No' not to restore auto-save.
  4. In the legend pane, select 'Legend' and enter the legend's name, description and author in the properties panel.
  5. Select 'Save Properties' to save the legend's properties.
  6. In the legend pane, select 'Class 1' and enter the class' name, description, code and colour in the properties panel.
  7. Select 'Save Properties' to save the class' properties.
  8. In the properties panel, select 'Add Horizontal Pattern' to add a horizontal pattern to the class.
  9. In the legend pane, select 'Horizontal Pattern 1' and enter the horizontal pattern's description, cover, occurrence and pattern type in the properties panel.
  10. Select 'Save Properties' to save the horizontal pattern's properties.
  11. In the properties panel, select 'Add Stratum' to add a stratum to the horizontal pattern.
  12. In the legend pane, select 'Stratum 1' and enter the stratum's description, presence type, portioning, and On Top details in the properties panel.
  13. While the stratum is highlighted in the legend pane, double click on all the elements in the element panel that are relevant to the stratum to add them.
  14. In the legend pane, select an element and enter its properties in the properties panel.
  15. Select 'Save Properties' to save the elements' properties.
  16. While the element is highlighted in the legend pane, select a characteristic group in the characteristics panel.
  17. Enter the element's characteristics in the characteristics sheet that appears above the characteristic groups.
  18. Select 'Save Characteristics' to save the elements' characteristics.
  19. From the shortcut toolbar select 'Validate' to check for any errors in the legend
  20. From the menu toolbar select 'File' then 'Export' to export the legend [Select 'Export' from the shortcut toolbar] / [Select 'Export diagram' from the legend pane]

II. Import Legend

  1. Importing a legend file.
    1. From the menu toolbar select 'File' then 'Import' [Select 'Import' from the shortcut toolbar].
    2. In the new 'Import Characterization Legend' window under 'Select Legend Source', select 'Legend File'.
    3. Click on the blue 'Select Legend' button and navigate and select the legend file to import [Drag and drop the legend file you wish to import into the 'Drag and Drop Legend File Here' area].
      Note: LChS can process .LChS, .lccs and .csv files. See the requirements in the 'File Types' panel.
    4. Click on the green 'Load Legend' button to import the legend.

  2. Importing from the Land Cover Registry.
    1. From the menu toolbar select 'File' then 'Import' [Select 'Import' from the shortcut toolbar].
    2. In the new 'Import Characterization Legend' window under 'Select Legend Source', select 'Land Cover Registry (LCLR)'.
    3. Wait for the registry to load and scroll through the list and select the legend you wish to import [Use the sort and filter buttons to rearrange the list as required].

III. Export Legend

  1. Validate the legend.
    1. From the shortcut toolbar select 'Validate'.
    2. Review the messages in the notifications panel and address any issues with the legend to allow exporting.

  2. Exporting the legend.
    1. From the menu toolbar select 'File' then 'Export' [Select 'Export' from the shortcut toolbar].
      (If 'Export' is greyed out, validate the legend and address any errors.)
    2. In the new 'Export Legend' panel select the export you require:
      Complete: Full export of the legend including LChS file, LCML XSD, legend diagram, class diagrams and CSV file in compressed ZIP file.
      LChS: Export of the legend as a LChS file.
      CSV: Export of the legend as a CSV file.

  3. Exporting the legend diagram.
    1. From the legend pane click 'Export diagram'.
      (If 'Export diagram' is inactive, validate the legend and address any errors.)
    2. Select the image format required: PNG, JPG or SVG.

  4. Exporting a class diagram.
    1. From the legend pane select the class' name tab to select the class you intend to export.
    2. From the legend pane click 'Export diagram'.
      (If 'Export diagram' is inactive, validate the legend and address any errors.)
    3. Select the image format required: PNG, JPG or SVG.

 

Land Cover Semantic Interoperability Workflows

I. Similarity Assessments

  1. From the menu toolbar select 'Resources' then 'Semantic Interoperability' then 'Similarity Assessment'.
  2. In the new 'Similarity Assessment' window under 'Compare legends for similarity by:', select 'Correspondence & Extensiveness' or 'Element Count' according to the comparison method preferred.
  3. Click on the blue 'Select Legends' button and navigate and select:
    - A reference legend file, against which other legends will be compared. (Ensure the reference legend file name includes the word 'Reference' for the system to identify it)
    - Legend files to be compared again the legend. (Hold Ctrl to select multiple files)
    [Drag and drop the reference legend and other legend files you wish to compare into the 'Drag and Drop Legend Files Here' area].
    Note: LChS can process .LChS, .lccs and .csv files. See the requirements in the 'File Types' panel.
  4. Click on the green 'Process Legends' button to perform the similarity assessment.
  5. Click on the similarity value to see the calculation of the similarity.
  6. Click on 'Export (CSV)' to export the similarity results.

II. Legend Reassignment

  1. From the menu toolbar select 'Resources' then 'Semantic Interoperability' then 'Legend Connector'.
  2. In the new 'Select Reference Legend' choose a reference classification system to map your appointed legend against.
  3. Click 'Next'
  4. In 'Load Appointed' either
    - Select 'Upload File' to upload your appointed legend file to be mapped against the reference classification. Click 'Select Legend File' to select the appointed legend file [Drag and drop the appointed legend into the 'Drag and drop legend file here' area].

    5. - Select 'Land Cover Registry (LCLR)' to select an appointed legend from the FAO Land Cover Registry to be mapped against the reference classification. Click on the 'Legend Name' or 'Actions' to select the appointed legend to import.
  5. Scroll down and click 'Next'.
    (Advanced users can adjust processing options in the window.)
  6. Scroll to the bottom of the window and click 'Start Processing'.
  7. Click 'View Results'.
  8. Click 'Export CSV', 'Export Excel' or 'Export JSON' to download the class reassignments that you can use in your GIS.
  9. To make adjustments or manually reassign classes:
    1. In the 'Matching Results' pane, select 'Log' to view the details of the class assignments
    2. From the 'Matching Details & Class Reassignment' pane click on the '+'.
    3. Scroll to the class you wish to reassign:
      • Select 'Alternatives' to directly assign already computed alternatives.
      • Select 'Reassign Class' pencil to select from all classes.
    4. Click 'Export CSV', 'Export Excel' or 'Export JSON' to download the class reassignments that you can use in your GIS.
